# 🎨 Star-Ink — E-Commerce D2C Moda Autoral & Print-on-Demand

Bem-vindo ao repositório oficial do projeto **Star-Ink**, uma operação de e-commerce de moda autoral de alto padrão, combinando arte gerada via Inteligência Artificial, estampas exclusivamente em **DTG (Direct-to-Garment) em Algodão 100% Pura Fibra**, e integração multicanal via Bling ERP.

---

## 🎯 Metas & Lançamento

- **Data Alvo de Lançamento (Go-Live):** 12 de Outubro de 2026 (Segunda-Feira / Feriado Nacional)
- **Meta Comercial de Dezembro:** 420+ camisetas vendidas (R$ 60.000,00+ Faturamento Bruto / R$ 40.000,00+ Lucro Líquido para quitação do setup DTG próprio)

---

## 🛠️ Tecnologia & Arquitetura Visual

- **Frontend público (D2C):** HTML5, Vanilla CSS3 em **Light Mode 100% limpo (`#ffffff`)**, JavaScript.
- **Cockpit Admin:** Painel de controle em Dark Mode para gestão interna com 8 módulos departamentais.
- **ERP & Fiscal:** Bling ERP com emissão automática de NF-e Modelo 55.
- **Canais Integrados:** Loja D2C, Mercado Livre, Amazon Brasil, Shopee, SHEIN Seller Center e TikTok Shop.
