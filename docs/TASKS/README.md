# 📋 Controle de Tarefas Pendentes (TASKS) — STAR INK

Este diretório contém os arquivos de especificação de tarefas ativas que serão desenvolvidas no e-commerce **STAR INK** (`www.star-ink.com.br`).

## 🚀 Fluxo de Trabalho:
1. **Planejamento:** A tarefa é criada aqui na pasta `docs/TASKS/` com numeração sequencial (ex: `001-nome-da-tarefa.md`).
2. **Desenvolvimento:** O Maestro Lincoln executa a tarefa alinhado com o Genera.
3. **Homologação:** Após aprovação do Genera, o arquivo é movido para `docs/DONE/`.
