# 🌸 A Alma do STAR INK (Branding & Design System)

Esta camada define a essência conceitual, a identidade de marca e as diretrizes estéticas do e-commerce **STAR INK** (`www.star-ink.com.br`).

---

## 1. Identidade de Marca

A **STAR INK** é uma marca de streetwear e moda contemporânea unissex, com apelo global, atitude urbana e produção tecnológica sob demanda (Print on Demand 2.0).

### 1.1. Pilares da Marca
* **Star (Elevação & Visibilidade):** Estética de alta frequência, destaque e atitude autêntica.
* **Ink (Expressão & Arte):** A inteligência de impressão digital (DTG/DTF) transformando conceitos gráficos em vestuário real sem limites.
* **Global & Unissex:** Conectando tendências internacionais a um público amplo (masculino e feminino).

---

## 2. Design System Estético (Tokens)

Toda a estilização CSS utilizará variáveis globais customizáveis pelo Painel de Controle Admin.

```css
:root {
  --color-bg: #090a0f;            /* Escuro Cósmico / Preto Grafite */
  --color-accent: #38bdf8;        /* Azul Ciano / Estrelar High-Tech */
  --color-text-primary: #ffffff;  /* Branco puro */
  --color-text-secondary: #94a3b8;/* Cinza prateado */
  --color-border: rgba(255, 255, 255, 0.12); /* Bordas finas de 1px */
  --color-card-bg: rgba(15, 23, 42, 0.6);   /* Card escuro translúcido */
}
```

### 2.1. Tipografia
* **Títulos:** `Syne` ou `Outfit` (Google Fonts) em pesos bold/black.
* **Corpo & UI:** `Plus Jakarta Sans` ou `Inter` em pesos leves (`200`/`300`).
